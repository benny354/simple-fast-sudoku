# 一个简单快速的数独

**v1.1** · 一个打开就能玩的轻量数独小游戏。

每次启动都会生成一道全新的随机数独，并验证题目有且只有一个解。无需安装、联网或额外运行环境，适用于 Windows 10 / 11 的 64 位电脑。

## 项目缘起

这个小游戏的起点，是大学里的一堂《大学物理 B（上）》课。

那时，我无意间看到了一道数独题，从此来了兴趣，索性买了一整套数独题集。往后每次上物理课，我都会撕下两张题目，一张留给自己，一张递给室友，比比谁先解出来。就这样，数独成了我们消磨枯燥课堂时光的小小竞赛。

至于《大学物理 B（上）》，后来也颇为应景地成了我大学里为数不多挂科的课程之一。

如今毕业已有一段时间，身边也难再找到能一起埋头解数独的人。于是，我做了这个简单的小程序，想把当年的一点乐趣留下来，也送给同样喜欢数独的你。

愿它陪你打发片刻闲暇。至于物理课，还是认真听比较好。

## 下载与运行

在 [v1.1 发布页面](https://github.com/benny354/simple-fast-sudoku/releases/tag/v1.1) 下载 `一个简单快速的数独.exe`，双击即可开始。运行时只需要这个 EXE。也可以下载便携压缩包，解压后运行。

下载源码后，也可按下方步骤自行编译。编译完成的 EXE 会生成在项目根目录。

## 怎么玩

每一行、每一列和每个 3×3 九宫格都要恰好填入 1—9。点击格子，再点击右侧数字或按键盘输入。深色数字是题目给定的，蓝色数字是自己填写的；红色表示行、列或宫内重复，不会直接泄露答案。

- **轻松 / 普通 / 挑战**：分别以 42 / 34 / 28 个已知数为目标。为保证唯一解，实际已知数可能略多。档位按已知数数量区分，并非严格的解题技巧评级。
- **笔记**：在空格内标记多个候选数。填写答案时，会自动删去同行、列、宫中的对应笔记。
- **撤销**：最多保留最近 256 步，包括笔记、擦除和提示。
- **提示**：填入选中格的正确答案；若该格已正确或不可填写，则选择下一个未完成格。
- **新的一局**：重新随机出题。有未完成的操作时会先确认。

| 按键 | 功能 |
| --- | --- |
| 1—9 / 小键盘数字 | 填写数字，或在笔记模式下切换候选数 |
| 方向键 / Tab / Shift+Tab | 移动选中格 |
| 空格 / P | 开关笔记 |
| Delete / Backspace / 0 | 擦除当前格 |
| Ctrl+Z | 撤销 |
| H | 提示 |
| F2 / Ctrl+N | 新题 |

计时从新题生成后开始，完成后停止。当前版本不保存进度，关闭后再次打开会生成新题。

## 为什么保证可解

先用随机回溯生成一个完整合法的终盘，再随机挖空。每次挖空后，求解器会搜索到最多两个解：只有恰好一个解时才保留这次挖空。整个过程始终保留唯一解，因此每一道实际生成的题都可以解开。随机种子优先来自 Windows 系统随机源，全部离线运行。

## 轻量设计

C + Windows 原生 API，使用系统字体和 GDI 绘制界面，不带网页引擎、Python 解释器、大型框架或外部素材包。运行时只有一个 EXE，源码和测试文件不需要一起复制。编译器缓存在用户的 LocalAppData 中，不随游戏分发。

## 重新编译和测试

在本文件夹打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

首次编译自动下载约 478 KiB 的 [Tiny C Compiler 0.9.27](https://bellard.org/tcc/)，并验证固定的 SHA-256；之后可离线编译。请先关闭已有的游戏窗口再覆盖 EXE。编译时使用的执行策略选项仅作用于该命令，不修改系统策略。

运行生成器测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test -PuzzleCount 1000
```

如果开发电脑已安装 Python，还可以用另一套独立求解器复验：

```powershell
python .\tests\verify_independent.py 300
```

`src/main.c` 为原生窗口和游戏交互，`src/sudoku.c` 为出题与求解算法，`tests/` 为开发测试。测试结果与实测性能见 `测试记录.md`。
